## Start-up (supply-ramp transients)

180 transients finished: 15 sections x T (-40 / 27 / 125 C) x final vdd (3.0 / 3.6 V) x ramp (10 us and 1 ms, simulated to 3x the ramp). Pass = mean iout over the last 5 % within +-5 % of the DC value at the same section/T/vdd (DC load 0.7 V, transient load NMOS diode, so a small difference is expected) and settled to 1 % before 90 % of the run.

- failures: **0**
- largest |final/DC - 1|: 0.13 % (ss_ll fast -40 C 3.0 V)
- longest settling to 1 % after the end of the ramp: 0.05 us (ss_hh fast 125 C 3.6 V)
- runs that needed a gmin retry (numerics in the first ns, vdd ~ 0): 8 (ll slow 125 C 3.0 V: gmin 1e-14; hh fast 125 C 3.0 V: gmin 1e-14; hh fast 125 C 3.6 V: gmin 1e-14; ff fast 125 C 3.0 V: gmin 1e-15; ff fast 125 C 3.6 V: gmin 1e-15; ff_ll fast 125 C 3.6 V: gmin 1e-14; ff_hh fast 125 C 3.0 V: gmin 1e-14; fs fast 125 C 3.6 V: gmin 1e-14)

## What this shows and what it does not

- Shows: the sky130 schematic port biases correctly at all listed corners, temperatures and supplies, starts up from a supply ramp, and the order of magnitude of its spread, supply sensitivity and TC.
- Does NOT show: mismatch / Monte Carlo (offset of the NMOS pair and mirrors is not simulated), layout parasitics, noise, PSRR vs frequency, enable/disable transients, aging, or any measured silicon behaviour. Device sizes are first-cut, not optimized.
- IHP sg13cmos5l reference (NOT sky130): bg_core_pd 3.83..6.37 uA over corners and temperature, tt 4.87 / 4.96 / 4.88 uA at -40 / 27 / 125 C. Listed only for orientation; the sky130 topology differs (self-cascode PMOS mirrors, R1B = 10/11 R1A kept).
