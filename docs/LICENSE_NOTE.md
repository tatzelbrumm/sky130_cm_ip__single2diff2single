# License note

The license of this IP block is **either Apache-2.0 or the Solderpad Hardware License v2.1 (SHL-2.1), pending approval by
the Chipalooza organizers.**

- `LICENSE` holds the Apache-2.0 text (the license the rules prefer).
- `LICENSES/SHL-2.1.txt` holds the SHL v2.1 text (copied from the predecessor IHP slot 7 repository).
- SHL v2.1 is a wraparound license to Apache-2.0: it incorporates the Apache-2.0 terms, adapts them to hardware (rights in
  designs, mask works, databases), and is permissive; its text lets a recipient choose to treat the work as released under
  Apache-2.0.
- The rules (Chipalooza Challenge #4, rules page): "Every design must be licensed under a standard open source license,
  preferably Apache 2.0. Other similar licenses will be considered. In no case may a design use any sources which would
  violate the terms of the source's license or the Apache 2.0 license."

Until the organizers decide, files carry `SPDX-License-Identifier: Apache-2.0`; if SHL-2.1 is chosen, the identifiers become
`SHL-2.1` and `LICENSE` is replaced by the SHL text. Third-party sources used: the sky130 PDK (Apache-2.0) and the
IIC-OSIC-TOOLS tool versions (their own open-source licenses); no other third-party design sources.
